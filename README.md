# 赤シート

学校などで配信された、赤字で答えが書かれているPDFを取り込み、赤シートのON/OFFで暗記できる無料Webアプリです。GitHub Pages上で動作します。

## 使い方

1. ロイロノート・スクールなどで配信されたPDFを、端末の「ファイル」または「ダウンロード」に保存します。
2. アプリの「PDFを選ぶ」から読み込みます。ドラッグ＆ドロップ、複数ファイル、公衆向けPDFのURL取り込みにも対応しています（1ファイル50 MBまで）。
3. 赤シートONで赤字を隠し、OFFで答えを確かめます。「押して答えを見る」は、押している間だけ答えを表示します。
4. 教材名・教科の変更はライブラリの「…」から。ページ・しおり・感度は自動保存されます。

初めての利用には、著作権上独立したオリジナルのサンプルPDFを同梱しています。

## 機能

- 日本語・画像を含むPDFの表示とページ移動、拡大・縮小
- 赤・ピンク・オレンジの画素を検出して隠す赤シート、感度調整
- 押している間だけ答えを表示
- IndexedDBによる教材の端末保存、続きから再開、ページのしおり
- 教材検索、教科分類、並べ替え、教材名の編集・削除
- 元のPDFをダウンロード
- スマートフォン対応、PWA用マニフェスト、初回読み込み後のオフライン利用
- キーボード操作：Spaceで切替、左右でページ移動、Bでしおり、Escでライブラリへ

## プライバシーと制約

PDF・学習記録は利用者のブラウザ内に保存されます。教材をアプリのサーバーへ送信する処理や、公開教材一覧はありません。Supabaseへの接続も行いません。端末間の同期はありません。ブラウザのデータ削除で保存教材も消えるため、元のPDFは必ず別途保管してください。共有端末では使用後に教材を削除してください。

ロイロノートなどの学校アカウントへログインする機能はありません。サービスで許可された方法でPDFを保存してから利用してください。URL取込みは、配信元がCORSによる外部取得を許可しているHTTPSの直接リンクのみ利用できます。

色検出のため、図や写真の赤い部分も隠れます。黒字の答えは隠れません。印刷・スキャン状態や色味によっては完全に隠れない場合があるため、学習前に確認してください。パスワード保護PDFは解除してから取り込んでください。教材の取り扱いは学校・配信元のルールに従ってください。本アプリはロイロノート・スクールの公式アプリではありません。

アプリの文字表示にはシステムフォントを利用します。PDF.js関連のフォント・CMap・画像デコーダーは同じ公開サイトに同梱し、PDF閲覧時に外部CDNへアクセスしません。

## ローカル開発

Node.js 24以降。

```sh
npm ci
npm run dev
```

```sh
npm test
npm run build
npm run preview
```

画素単位の検証は `npm test`。ブラウザの操作検証は、開発サーバーを起動してから `npm run test:e2e`。Chromiumが必要です（`npx playwright-core install chromium`、または `CHROMIUM_PATH` で実行ファイルを指定）。`AKASHEET_TEST_URL` で検証先、`AKASHEET_QA_DIR` でスクリーンショットの保存先を変更できます。

オフライン・サブディレクトリ配信の検証は、`npm run build` 後、別ターミナルで `npm run preview -- --port 4173 --base /annki/` を起動し、`npm run test:offline` を実行します。

## GitHub Pagesへの公開

GitHubの **Settings → Pages → Build and deployment → Source → GitHub Actions** を選択します。`main`へのpushで `.github/workflows/pages.yml` が検証・ビルド・公開します。初回push後にPagesを有効化した場合は、Actionsのワークフローを再実行してください。

相対パスのビルドなので、`https://amongushahahasus-sudo.github.io/annki/` などのサブディレクトリへ配置できます。Secrets・サーバー・APIキーの設定は不要です。

PDF.jsを更新する場合は、`node_modules/pdfjs-dist/{cmaps,standard_fonts,wasm}` を `public/pdfjs/` の同名ディレクトリへコピーし、ライセンスも更新してください。
